# Releases

No release has been published yet. The release workflow (`.github/workflows/release.yml`) builds
and verifies a release artefact and the node image on demand and keeps them as workflow artefacts.
It publishes nothing. See [Verify a release before installing it](docs/how_to/verify_a_release.md).

Each release records its version, what changed, and any action an operator must take before or
after upgrading.
