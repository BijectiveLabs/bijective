## What a redistribution keeps

Anyone may use, change and redistribute this code, commercially or not. A redistribution in source
or binary form keeps what the licence requires (section 4):

- a copy of `LICENSE`;
- the `NOTICE` file, readable wherever the redistribution shows third-party notices;
- every copyright, licence and attribution notice in the source files it carries, including the
  `SPDX-License-Identifier` and copyright lines at the top of each file;
- a prominent notice in every file it changed, stating that it was changed.

## Using the name

| Use | Allowed |
|---|---|
| Saying a product is built on, derived from or compatible with Bijective | Yes, in plain text, without implying endorsement |
| Redistributing an unmodified release under its own name | Yes |
| Distributing a modified version under the Bijective name, or a name that can be confused with it | No. A modified version is named differently |
| Publishing packages, images or crates under the `bijective` name or prefix | No, except by Bijective Labs |
| Using the name in a way that suggests Bijective Labs reviewed, supports or certifies a product | No, unless agreed in writing |

Identifiers in the source, such as crate, package and module names, are part of the code and may
stay as they are in a modified version. Only the name a distribution is offered under must differ.
