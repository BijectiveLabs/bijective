# Store

A sample record for the quick start. `market-sample/` is a generated book on a stream named
`market-sample`, which `bijective.json` at the repository root names, so a first backtest needs no
venue and no argument. It is not a venue recording, and no claim measured on it says anything about
a real market ([try the platform without installing it](../docs/how_to/try_the_platform_without_installing_it.md)).
