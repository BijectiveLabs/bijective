# Public functions with no production reader, and why each is allowed to have none.
#
# Format: <name> <TAB> <path relative to the repository root> <TAB> <reason>
#
# A public function nothing calls is either a capability the platform declared and forgot to use,
# or a forward declaration whose consumer is not built. The first kind has cost this platform
# real defects - a refused cancel routed away from reconciliation, a venue curated for market
# data able to receive orders, a hard rule bypassed by the file it was meant to guard. The
# second kind is legitimate and must still be named, because the two look identical from here.
#
# An entry whose function now has a reader, or no longer exists, is stale and fails this gate.
# The list is meant to shrink.
